# 文献综述 — Step 10: 全文润色器

## 概述

对初稿全文进行学术语言润色，消除写作中的"AI 味"和"翻译腔"，提升学术表达的流畅性和地道性。这是投稿前的最后一道语言质量关卡。

## 前置条件

- 已完成初稿 `full_draft.md`
- **推荐：已完成 `lr-citation-verify`**——引用验证报告显示无 FAIL 项。如有未验证的引用，先回退修复
- 已确定目标期刊（推荐：已完成 `lr-journal-select`）

## 产出文件

- `polished/polished_draft.md`：润色后的全文

## 润色维度

### 中文项目润色清单

| 维度 | 检查内容 | 示例 |
|------|----------|------|
| 术语规范 | 首次出现标注英文 | "肿瘤微环境（tumor microenvironment, TME）" |
| 避免口语化 | 去除"很""非常""特别"等口语化表述 | "很明显"→"显著" |
| 句式多样性 | 被动/主动交替，长短句穿插 | 避免连续 3 句以上相同句式 |
| 段落节奏 | 150-300 字/段，论点-证据-过渡三段论 | 避免超长段落（>500 字） |
| 学名缩略词 | 缩写首次出现全称，<3 次出现不缩写 | "三级淋巴结构（tertiary lymphoid structures, TLS）" |
| 引用密度 | 每个论点 2-4 篇文献，避免过度堆砌 | "A 等人[1] 发现了 X；B 等人[2] 也发现了 X" → "X 已被多项研究证实[1-4]" |
| 逻辑连接 | 检查"然而""因此""此外"等连接词的使用 | 确保逻辑关系正确 |
| 标题层级 | 一级标题（章）、二级标题（节）、三级标题（小节）层次清晰 | 避免跳级 |
| 数字表达 | 数字与单位的统一（阿拉伯数字 + 国际单位） | "100 例"而非"一百例" |

### SCI 英文项目润色清单

| 维度 | 检查内容 | 示例 |
|------|----------|------|
| 语法 | 主谓一致、时态正确、冠词使用 | "the data suggest" (not "suggests") |
| 被动语态 | 主体段落以被动语态为主 | "It has been demonstrated that..." |
| 主动语态 | 总结和展望适当使用主动语态 | "We propose that..." |
| 句式多样性 | 避免连续以 "This study..." 开头 | 交替使用 "Moreover..."、"Notably..."、"Consistent with..." |
| 词汇精确度 | 使用精确动词 | demonstrate > show, elucidate > explain, underscore > emphasize |
| 段落结构 | Topic → Evidence → Transition | 每段 100-200 words |
| 基因/蛋白命名 | 基因斜体，蛋白正体 | *KRAS* (gene), KRAS (protein) |
| 术语一致性 | 全篇使用统一的术语 | "tumor microenvironment" 不混用 "tumour microenvironment" |
| 缩写规范 | 首次全称 + 缩写，频繁使用的缩写 | "tumor microenvironment (TME)" |
| 移除冗余 | 删除不必要的 filler words | "It is worth noting that..." → 直接陈述 |
| 段落过渡 | 检查段间和节间的过渡句 | 确保逻辑递进 |
| 引用格式 | 统一引用格式 | Vancouver [1] 或 APA (Author, Year) |

### 学术严谨性检查（中英通用）

| 检查项 | 说明 |
|--------|------|
| 数据准确性 | 所有引用的数据是否可追溯到精读笔记 |
| 推测区分 | 推测性内容是否标注了不确定性 |
| 结论强度 | 结论强度是否与证据强度匹配 |
| 矛盾处理 | 互斥的研究结果是否有讨论而非回避 |
| 过度声称 | 避免"首次""最大""最重要"等绝对化表述 |

### "去 AI 味"专项检查

AI 辅助写作常有固定模式，润色时需要破除：

| AI 常见模式 | 改进方向 |
|-------------|----------|
| "In recent years, ... has attracted considerable attention" | 改为具体时间/具体进展 |
| "Numerous studies have shown that..." | 引用具体研究 |
| "It is worth noting that..."（冗余） | 直接陈述 |
| 段落以 "Furthermore" 连续开头 | 交替使用其他连接词 |
| 过度使用 "However" | 减少频率，用具体转折 |
| 每段都是"发现→引用→发现→引用" | 增加批判性讨论和综合 |

## 执行步骤

### 1. 逐章润色

对每章依次执行以上所有维度的检查。

### 2. 全文一致性检查

- 术语统一：搜索全文中出现的同义但不同词形的术语
- 引用一致性：所有引用是否在参考文献列表中有对应
- 缩写一致性：全文中同一缩写是否总是指同一概念

### 3. 生成润色报告

在 polished_draft.md 末尾附润色报告：

```markdown
## 润色变更报告

| 类别 | 变更数量 | 主要变更 |
|------|----------|----------|
| 语法修正 | X 处 | ... |
| 术语规范 | X 处 | ... |
| 句式优化 | X 处 | ... |
| 逻辑调整 | X 处 | ... |
| 引用修正 | X 处 | ... |
| 去AI味 | X 处 | ... |

## 尚需人工确认
- [ ] [列出AI无法确定、需要领域专家判断的内容]
```
